## Comanda pentru tine (doar citește, nu schimbă nimic)
Deschide PowerShell (nu e nevoie de administrator pentru cele mai multe) și lipește:

```powershell
Get-WinEvent -FilterHashtable @{LogName='System'; StartTime='2026-10-29 22:30'; EndTime='2026-10-30 00:30'} |
  Where-Object { $_.Id -in 41,6008,1074,1076,6005,6006,19,20,43,1001 -or $_.ProviderName -like '*WHEA*' -or $_.Level -le 2 } |
  Select-Object TimeCreated, Id, ProviderName, LevelDisplayName, @{n='Mesaj';e={($_.Message -split "`n")[0]}} |
  Format-Table -AutoSize -Wrap
```

Cum se citește ce iese:
- **41** (Kernel-Power) + **6008**, fără **1074** înainte → oprire bruscă, fără închidere: de obicei **curent** sau blocare.
- **1074** cu numele unui program (de ex. TrustedInstaller / Windows Update) → repornire **cerută de Windows Update**.
- **1001** (BugCheck) cu un cod → **ecran albastru**.
- **WHEA-Logger** → eroare **hardware** (procesor, memorie, placă).

Dacă iese pană de curent, ce ar ajuta: o sursă UPS (ține calculatorul pornit câteva minute și îl lasă să se oprească curat).
Dacă iese Windows Update: orele active / amânarea repornirilor în timpul nopții. Nu schimb nimic din astea fără „da”-ul tău.
